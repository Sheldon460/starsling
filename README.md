Starsling is an endless gravity-slingshot arcade game: drag the comet back, release to sling it through a starfield, ride a planet's gravity for a gravity-assist bonus, catch star-shards to build a combo, and dodge drifting asteroids and the edge of the void. Three lives, rising speed and hazard density, and a palette that shifts from Dusk Ember to Teal Nebula to Violet Deep as your score grows. Pure Canvas 2D with synthesised WebAudio sound — no libraries, no assets, no network. Keyboard and mouse (or touch): drag to aim with a gravity-bent trajectory preview, Space to start, P to pause, M to mute.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
